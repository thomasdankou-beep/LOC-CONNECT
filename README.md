# LOC-CONNECT
site de location de matériel qui regroupe les loueur au client

## Maquette front (Lot 1)

Dossier `web/` : Next.js (App Router) + TypeScript, données fictives. Basé sur le cahier des charges technique LOC'CONNECT.

```bash
cd web
npm install
npm run dev   # http://localhost:3000
```

Pages : accueil, catalogue (recherche, filtres, tri, pagination), fiche produit, panier multi-loueurs, paiement (HOLD 15 min simulé), espace loueur, compte client.
